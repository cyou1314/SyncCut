# SyncCut 本地素材导入（第一版）

当前支持：飞书多维表格导出的 CSV + 音频目录。

- 中文字段映射到统一素材模型。
- 按附件文件名精确匹配；重名文件报错，不猜测。
- 先生成预览计划和逐行错误，未确认前不复制文件。
- 显式 confirm 后复制到本地素材库，计算 SHA-256。
- 同素材同内容重复导入会跳过；内容变化新增版本。
- 原始文件和既有版本不会被覆盖或删除。
- 无显式 SyncCut ID 时使用项目/集数/场景/镜头/名称派生 ID；建议在飞书表增加稳定的“SyncCut ID”列，避免改名后被识别为新素材。

Node.js 22+。本版尚未实现 XLSX、ZIP、图形界面及 PostgreSQL 集成；先验证 CSV 到本地版本库的安全闭环。
