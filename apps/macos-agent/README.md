# SyncCut macOS Agent

macOS 13+ 菜单栏助手。当前提供本地素材导入、素材库检索/试听/归档和内容哈希缓存；团队配对、云端任务与剪映自动化仍在后续阶段。

## 本地素材导入

首次使用时自动准备本机素材库。在“导入”页面点击“添加音频”，可多选音频文件和文件夹。确认扫描结果后导入；素材名称来自文件名，类型和其他信息可在素材库的“编辑信息”中补充。可点击“素材库”更换保存位置。重复选择和不支持的文件会显示原因；未变化的素材不会重复导入。试听是否可用取决于 macOS 的解码支持。

本地直接导入根据标准化的来源路径生成稳定身份：同一路径的内容改变会产生新版本，不同路径的同名文件分别记录。移动或重命名源文件会作为新来源处理。来源身份仅存路径的哈希，不记录原始路径。

## 高级导入（CSV + 音频目录）

启动后点击菜单栏 SyncCut 图标，在“导入”页面依次选择：

1. **素材清单**：CSV 文件（UTF-8，支持中文列名）。
2. **音频目录**：包含音频附件的文件夹，可递归扫描子目录。
3. **素材库**：用于保存导入音频版本和 `manifest.json` 的目标文件夹。

点击“检查并预览”后，助手会显示可导入数量、新素材、已有素材和逐行错误。只有预览无错误时才可点击“确认导入”。

支持导入音频：MP3、WAV、M4A、AAC、AIFF/AIF、FLAC、OGG、OPUS。

导入安全规则：
- 按附件文件名精确匹配；重名不猜测，报告错误。
- SHA-256 校验源文件及复制结果。
- 相同音频不重复创建版本；元数据变化只更新 manifest。
- 音频内容变化时新增版本，保留历史版本。
- 不删除、不移动、不覆盖原始音频。
- 预览后如果源文件变化，拒绝导入并要求重新预览。
- 通过系统文件选择器获取访问权限，并在操作结束后释放权限。

## 素材库管理

切换到“素材库”页面后，可以：

- 按素材名称、项目、集数、场景、镜头编号、备注和标签搜索。
- 按音乐、音效、配音、环境音筛选。
- 查看每条素材的版本数量、文件大小和版本 SHA-256。
- 试听最新版本或指定历史版本（取决于 macOS 对该音频编码的解码支持）。
- 查看备注、标签和版本历史，并在 Finder 中定位任意版本文件。
- 将不再使用的素材归档，或从归档列表恢复。
- 记住上次选择的素材库目录；通过安全作用域书签在下次启动时恢复访问。

**归档不是物理删除。** 归档只在 manifest 中写入 `archivedAt`，将素材从“在用”列表隐藏；音频文件和全部历史版本均保留。重新导入已归档素材不会自动解除归档。当前版本没有物理删除入口，避免误删源素材和历史版本。

## 本地缓存

- 缓存按 SHA-256 内容寻址。
- 命中缓存时重新计算哈希，不信任仅凭文件名存在的缓存。
- 缓存损坏时重新复制并校验。

## 命令行高级导入

XLSX 与 ZIP 目前通过 API 包中的命令行入口执行，支持 CSV/XLSX + 音频目录或 ZIP：

```bash
cd apps/api
npm run import:media -- --table "/path/素材清单.xlsx" --audio-zip "/path/音频附件.zip" --library "$HOME/Music/SyncCut-Media"
```

命令行会先预览；只有输入大写 `IMPORT` 才执行写入。详细规则见 `apps/api/LOCAL_IMPORT.md`。

## 本机编译、测试与启动

需要 Mac + Xcode Command Line Tools。在本目录运行：

```bash
swift build
swift test
swift run
```

GitHub Actions 会在 macOS runner 上执行构建和 Swift 单元测试；API 导入逻辑也有独立自动化测试。实际菜单栏交互、音频试听和文件访问仍需在真实 Mac 上验收。

## 云端设备配对（M2.3）

1. 在 SyncCut Web 控制台「Mac 设备」区域生成一次性配对码（10 分钟有效）。
2. 在菜单栏助手切换到「设备」页面。
3. 填入正式云端 API HTTPS 地址、配对码和设备名称。
4. 点击「配对这台 Mac」。

设备 Token 仅在配对响应中返回一次，并保存到 macOS 钥匙串；不写入 UserDefaults、素材清单或日志。设备可在 Web 控制台单独撤销。开发环境允许使用 http://127.0.0.1 / localhost；远程服务器必须使用 HTTPS。

当前 M2.3 已完成配对、设备身份查询、心跳和撤销 API；任务拉取、签名下载与 Mac 执行结果回传仍在开发中。
## 云端设备配对与自动素材同步（M2.3）

1. 在 SyncCut Web 控制台「Mac 设备」区域生成一次性配对码（10 分钟有效）。
2. 在 Mac 助手「设备」页面填写云端 API HTTPS 地址和配对码。
3. 配对成功后，设备凭证保存在 macOS 钥匙串；控制台可单独撤销设备。
4. Web 控制台「发送素材到 Mac」区域选择已归档到对象存储的素材版本和目标设备。
5. Mac 助手配对后每 10 秒自动轮询任务，下载签名 URL，校验文件大小与 SHA-256，并写入 Application Support/SyncCut/Cache/CloudAssets。

CloudAssets/manifest.json 记录素材版本、原始文件名、大小、哈希和缓存相对路径。相同 SHA-256 的文件复用物理缓存文件。

当前 sync_assets 任务只负责云端到 Mac 的下载、校验和缓存，不会声称已经导入剪映。剪映素材库批量导入属于 M2.4。
