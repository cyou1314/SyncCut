# Contributing

Thanks for helping improve SyncCut.

## Before opening a pull request

1. Read the product, architecture, and Jianying adapter documents in docs/.
2. Keep the initial release macOS-first.
3. Do not add a Jianying or CapCut CLI workflow.
4. Never overwrite source media or the original Jianying project.
5. Review dependency licenses before adding third-party code or assets.
6. Include reproduction steps and verification evidence for behavior changes.

## Pull request expectations

- Keep changes focused.
- Explain user-visible behavior and affected modules.
- State what was tested and what was not tested.
- Never include user media, credentials, cookies, or private project files.
