# 剪映适配器实施与安全边界

## Import Adapter：媒体库导入

优先评估 macOS Accessibility：
- 检查剪映进程是否运行。
- 读取窗口、按钮和菜单项。
- 打开导入对话框并传入本地缓存文件路径。
- 等待素材库出现导入结果，再回传逐文件状态。
- 若界面结构变化或控件定位失败，停止并要求用户确认；不使用盲目坐标连点。

## Timeline Adapter：时间轴套用

- 用户先选择目标项目。
- 默认生成副本，源项目保持只读。
- 执行前检查工程版本和工程状态。
- 未知版本不写入。
- 按毫秒保存片段位置、素材入出点、轨道、音量和淡入淡出。
- 写入前后计算工程文件哈希并生成审计日志。
- 完成后在剪映中打开副本，要求人工播放抽检。

## 本机探查结果

- macOS 14.6.1，剪映专业版 11.3.0：在用户创建的空白测试草稿中，通过剪映“文件 → 导入”对应的原生文件对话框导入 WAV，素材列表出现该文件；时间轴保持为空。
- 系统辅助功能树可识别“文件 → 导入”菜单以及导入后的素材条目，但本次观察中窗口标题未提供可可靠识别的草稿名称。导入操作会改变当前草稿的素材列表，不能将它当成对所有工程独立的全局素材库。
- 当前尚未实现完整的一键导入，也没有验证从 SyncCut 自动控制剪映。不得对当前草稿执行自动导入，直到目标副本能够被可靠识别且完整流程通过验证。
- `JianyingImportPreparation` 只校验已选素材来自指定素材库、文件大小和 SHA-256 与记录一致，并去重；它不会启动或操纵剪映，也不会将素材导入剪映。

## 明确不做

- 不覆盖原工程。
- 不直接修改正在打开的工程文件。
- 不读取或复制剪映登录 Cookie。
- 不修改剪映官方应用包或官方库。
- 不使用剪映/CapCut CLI 工作流。
- 不在未验证版本上执行时间轴写入。

## 进入适配器开发前需要的本机信息

1. Mac 芯片：Apple Silicon 或 Intel。
2. macOS 版本。
3. 剪映专业版版本号和构建号。
4. 当前剪映项目是否为本地草稿。
