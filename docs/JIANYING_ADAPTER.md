# 剪映适配器实施与安全边界

## Import Adapter：媒体库导入

优先评估 macOS Accessibility：
- 检查剪映进程是否运行。
- 读取窗口、按钮和菜单项。
- 打开导入对话框并传入本地缓存文件路径。
- 等待素材库出现导入结果，再回传逐文件状态。
- 若界面结构变化或控件定位失败，停止并要求用户确认；不使用盲目坐标连点。

## Timeline Adapter：时间轴套用

- 用户先选择目标项目。
- 默认生成副本，源项目保持只读。
- 执行前检查工程版本和工程状态。
- 未知版本不写入。
- 按毫秒保存片段位置、素材入出点、轨道、音量和淡入淡出。
- 写入前后计算工程文件哈希并生成审计日志。
- 完成后在剪映中打开副本，要求人工播放抽检。

## 明确不做

- 不覆盖原工程。
- 不直接修改正在打开的工程文件。
- 不读取或复制剪映登录 Cookie。
- 不修改剪映官方应用包或官方库。
- 不使用剪映/CapCut CLI 工作流。
- 不在未验证版本上执行时间轴写入。

## 进入适配器开发前需要的本机信息

1. Mac 芯片：Apple Silicon 或 Intel。
2. macOS 版本。
3. 剪映专业版版本号和构建号。
4. 当前剪映项目是否为本地草稿。
