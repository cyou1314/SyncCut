# SyncCut 飞书多维表格模板

## 建议结构

一个 Base 可以包含“项目表”和“素材表”。首期也可以只建素材表，将项目/集数/场景作为字段。

### 素材表字段

| 字段名 | 类型 | 必需 | 说明 |
|---|---|---:|---|
| 素材名称 | 文本 | 是 | 音乐或音效名称 |
| 素材类型 | 单选 | 是 | 音乐 / 音效 / 配音 / 环境音 |
| 音频附件 | 附件 | 是 | 主音频文件；首期一条记录一个主文件 |
| 项目 | 文本或关联 | 是 | 所属短剧/项目 |
| 集数 | 数字或文本 | 否 | 如 15 或 EP015 |
| 场景 | 文本 | 否 | 场景名称 |
| 镜头编号 | 文本 | 否 | 如 S15-023 |
| 标签 | 多选 | 否 | 悬疑、紧张、转场等 |
| 备注 | 多行文本 | 否 | 使用说明 |
| 开始时间（秒） | 数字 | 否 | 时间轴起点 |
| 素材入点（秒） | 数字 | 否 | 源音频入点 |
| 素材出点（秒） | 数字 | 否 | 源音频出点 |
| 目标音轨 | 单选 | 否 | A1 / A2 / A3 / A4 |
| 音量（%） | 数字 | 否 | 默认 100 |
| 淡入（秒） | 数字 | 否 | 默认 0 |
| 淡出（秒） | 数字 | 否 | 默认 0 |
| SyncCut 状态 | 单选 | 否 | 待同步 / 已同步 / 导入成功 / 失败 |
| SyncCut 版本 | 数字 | 否 | 由同步流程维护 |
| 修改时间 | 最后更新时间 | 是 | 用于补偿同步 |

字段名称可自定义，SyncCut 通过字段映射绑定字段 ID，不依赖固定列顺序。

## 规则

1. 一条记录代表一个逻辑素材。
2. 首期每条记录只设置一个主音频附件；多版本通过附件替换和 SyncCut 版本历史管理。
3. 替换附件后，SyncCut 记录新的 file_token 和文件哈希，不覆盖本地旧缓存。
4. 不要将多个不同音效塞入同一条记录的附件字段。
5. 时间轴参数使用秒和百分比；SyncCut 内部统一转换为毫秒和整数百分比。
6. “SyncCut 状态”建议由 SyncCut 回写；若暂时未授予写权限，该字段可以只读或先不使用。
7. 业务字段与系统字段分组展示，避免团队成员误改系统状态。
