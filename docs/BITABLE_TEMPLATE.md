# SyncCut 素材管理中心：手动建表

目前请在飞书手动新建名为「SyncCut 素材管理中心」的多维表格，创建「素材表」。一条记录只放一个音频附件；飞书是主数据源。以下字段名可以调整，但类型须对应，连接时应保存各字段 ID。

| 字段 | 类型 / 选项 |
|---|---|
| 素材名称 | 文本（主字段） |
| 素材类型 | 单选：音乐、音效、配音、环境音 |
| 音频附件 | 附件（每条一份） |
| 项目名称、集数、场景、镜头编号 | 文本 |
| 标签 | 多选 |
| 备注 | 多行文本 |
| 开始时间、素材入点、素材出点 | 数字，单位秒 |
| 目标音轨 | 单选：A1、A2、A3、A4 |
| 音量 | 数字，单位百分比（100 表示原音量） |
| 淡入、淡出 | 数字，单位秒 |
| SyncCut 同步状态 | 单选：待同步、已同步、导入成功、失败 |
| SyncCut 版本 | 数字 |
| 修改时间 | 最后更新时间 |

当前同步只读取，不回写状态或版本；替换附件后保存新的附件元数据版本，不复制音频到数据库。相同 file_token 和元数据的内容变化无法仅凭 API 元数据检测，后续下载时需要计算哈希。

飞书官方支持 API 创建 Base、数据表和字段，但完整初始化和失败恢复尚未实现。**不要把手动说明当作已创建的真实表格。**应用身份创建的 Base 属于应用，成员可能仅有阅读权限；实际协作前需配置文档权限。相关官方说明：[创建 Base](https://open.feishu.cn/document/introduction-2)、[多维表格接口](https://open.feishu.cn/document/agile-project-cycle-management-based-on-bitable/introduction)。
