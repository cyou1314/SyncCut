# SyncCut 产品需求（飞书优先 MVP）

## 1. 产品定位

SyncCut 是飞书与剪映之间的素材同步和本地自动化桥梁，不是飞书文档的替代品。

首期仅支持 macOS + 剪映专业版。飞书多维表格负责团队素材协作；SyncCut 负责同步任务、Mac 本地缓存和剪映操作。

## 2. 用户范围

- 当前阶段：一个飞书企业/团队试点。
- 架构要求：从第一天支持多租户数据模型。
- 后续阶段：完成飞书应用商店应用/跨企业安装授权后，允许其他团队分别接入自己的飞书空间。

## 3. 产品组成

### 飞书多维表格（主要操作界面）

团队成员在飞书完成：
- 新增项目/集数/场景/镜头；
- 上传音乐、音效、配音、环境音；
- 填写素材名称、类型、标签和备注；
- 设置时间轴位置、轨道、音量、淡入淡出；
- 查看 SyncCut 同步状态。

### SyncCut Web 控制台（管理与诊断）

- 绑定/解除飞书 Base。
- 配置字段映射和同步规则。
- 查看飞书连接状态和最近同步时间。
- 管理 Mac 设备和撤销设备。
- 查看同步队列、失败原因和重试记录。
- 管理团队成员角色（身份以飞书为准）。

不在 Web 控制台重复编辑飞书中的素材表。

### SyncCut Mac 助手

- 菜单栏常驻。
- 绑定团队和设备。
- 接收同步任务。
- 下载音频、校验 SHA-256、缓存和去重。
- 执行批量导入或时间轴套用。
- 回传任务结果。

## 4. 角色

| 角色 | 权限 |
|---|---|
| 租户管理员 | 连接飞书 Base、配置字段映射、邀请/移除 SyncCut 成员、管理设备 |
| 素材编辑者 | 在飞书维护素材；在 SyncCut 创建导入/套用任务 |
| 剪辑人员 | 试听、选择素材、执行套用、查看任务 |
| 只读成员 | 查看素材与同步状态 |

飞书成员权限和 SyncCut 角色映射需要在登录后校验，不能仅凭前端隐藏按钮。

## 5. Bitable 素材记录字段

默认字段建议见 `docs/BITABLE_TEMPLATE.md`。至少需要：
- 素材名称、素材类型、音频附件；
- 项目、集数、场景、镜头编号；
- 标签、备注；
- 开始时间、素材入点、素材出点、目标音轨；
- 音量、淡入、淡出；
- 更新时间、SyncCut 状态。

字段名允许配置映射，避免强制用户完全照搬模板。

## 6. 两种一键套用方式

### A. 批量导入素材库

1. 在飞书记录中选择素材或标记为“待导入”。
2. SyncCut 收到变更通知并刷新记录。
3. 用户在 SyncCut 控制台或 Mac 菜单栏选择导入任务。
4. Mac 下载附件、校验哈希、去重。
5. 通过 macOS 可访问性/UI 自动化适配器导入剪映。
6. 回传逐文件结果；失败项可单独重试。

### B. 套用到时间轴

1. 飞书记录包含完整的时间轴参数。
2. 用户选择目标剪映项目并发起套用。
3. SyncCut 冻结素材版本和参数。
4. Mac 检查剪映版本、项目状态并创建工程副本。
5. 适配器在副本中插入音频片段、设置轨道和音量/淡入淡出。
6. 完成后打开副本供用户播放抽检。
7. 回传副本位置和逐条结果。

## 7. 同步与版本规则

- 飞书是源数据，SyncCut 内部索引可重建。
- 一条 Bitable 记录对应一个素材主记录。
- 附件变更产生新的 asset_version，不静默覆盖历史版本。
- 任务创建时固定素材版本；任务执行期间飞书再更新，不改变当前任务内容。
- Webhook 重复投递不重复创建任务。
- Webhook 丢失由定时补偿同步修复。
- 已被剪映工程引用的本地缓存不自动清理。

## 8. 首期非目标

- Windows 助手。
- 自建多人文档编辑器。
- 云端保存全部音频主文件。
- 多人同时远程控制同一台剪映。
- 自动混音和母带处理。
- 未经验证直接修改剪映工程格式。
- 自动注册飞书企业或绕过飞书应用审核。

## 9. 验收标准

- 团队成员在飞书新增/修改素材后，SyncCut 能收到通知并刷新对应记录。
- Webhook 重复触发不会生成重复版本或重复导入任务。
- 飞书附件下载后 SHA-256 与本地文件一致。
- 不同 tenant_id 的连接、记录、设备和任务完全隔离。
- Mac 离线后重新上线能继续拉取任务。
- 批量导入失败可按文件重试，不重复处理成功文件。
- 时间轴套用不修改源工程；未知剪映版本拒绝写入。
