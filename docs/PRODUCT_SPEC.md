# SyncCut 产品需求文档（MVP）

## 1. 产品目标

把在线协作文档中的音乐、音效、配音和环境音素材，转化为可直接交付剪映的可执行素材清单。

首期 macOS + 剪映专业版，支持两种操作：
- 导入素材库：批量同步选中素材到 Mac，并导入剪映媒体库。
- 套用到时间轴：按每项素材的时间、轨道、音量、淡入淡出参数执行。

## 2. 用户角色

| 角色 | 权限 |
|---|---|
| 工作区管理员 | 创建项目、邀请成员、配置权限、管理素材 |
| 素材编辑者 | 上传或替换素材、编辑标签和套用参数 |
| 剪辑人员 | 查看试听、创建同步任务、查看结果 |
| 只读成员 | 查看文档和试听，不可修改 |

## 3. 主要页面

1. 工作区与项目总览
2. 项目协作文档
3. 音乐与音效素材清单
4. 素材详情与试听
5. 时间轴套用配置
6. 同步任务与失败重试
7. 成员权限和活动记录
8. Mac 助手设备管理

## 4. 素材字段

基本信息：名称、类型、项目、集数、场景、镜头编号、标签、备注。
文件信息：扩展名、MIME、大小、时长、采样率、声道、位深、SHA-256。
版本信息：版本号、上传人、上传时间、替换说明、旧版本引用。
套用信息：开始时间、素材入点、素材出点、目标音轨、音量、淡入、淡出。
状态：云端可用、本地已缓存、已导入剪映、版本待更新、失败。

## 5. 协作规则

- 一条素材对应一条数据库记录；多人更新不同素材时互不覆盖。
- Supabase Realtime 推送素材新增、修改和删除事件。
- 同一素材使用 version 乐观锁；版本不匹配时提示冲突，不静默覆盖。
- 替换素材保留历史版本；已在剪映使用的旧版本不自动替换。
- 活动记录保存操作者、操作类型、时间和对象 ID。

## 6. 一键导入素材库

1. 网页选择一个或多个素材。
2. 创建 import_media 同步任务。
3. Mac 助手收到任务并下载文件到临时目录。
4. 校验 SHA-256、文件大小和音频元数据。
5. 按内容哈希去重并移动到本地缓存目录。
6. 通过适配器执行剪映导入。
7. 返回逐文件结果；失败项可重试，成功项不重复下载。

## 7. 一键套用时间轴

1. 网页选择素材并配置开始时间、轨道、音量、淡入淡出。
2. 创建 apply_timeline 任务并冻结当前素材版本。
3. Mac 助手检查剪映版本、工程路径和工程状态。
4. 复制工程到新的输出目录，不直接修改源工程。
5. 在副本中执行音频片段插入。
6. 结构校验后在剪映中打开副本，供用户检查。
7. 回传执行日志和副本路径。

## 8. 非目标

- 多人同时远程操作同一台剪映桌面。
- 自动替换已在时间轴上的素材。
- 自动混音、响度母带和复杂音频修复。
- Windows 客户端。
- 自动生成音乐或音效。
- 读取剪映账号数据或上传工程中的无关媒体。

## 9. 验收标准

- 10 个素材可一次创建导入任务；成功项不会因失败项而重复下载。
- 相同 SHA-256 的素材在本地只缓存一份。
- 两名成员同时编辑不同素材，双方数秒内看到更新。
- 同一素材发生并发修改时出现冲突提示。
- 时间轴套用不修改原始工程；失败时保留源工程并写入任务日志。
- 任务记录可定位项目、素材版本、设备、操作者和执行结果。
