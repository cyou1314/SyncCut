# M2 实施进度

## 当前目标

将 SyncCut 从本地交互原型推进为可登录、可共享、可实时更新的云端工作区。

## 阶段拆分

- [x] M2.1a：数据库增量迁移（用户资料、工作区 owner 自动成员、素材元数据、私有音频 bucket、存储 RLS、Realtime 发布）。
- [ ] M2.1b：Supabase 项目创建与迁移实测。
- [ ] M2.2：Web 登录、注册、会话恢复、退出登录。
- [ ] M2.3：工作区创建、项目创建和项目列表。
- [ ] M2.4：音频上传、试听、素材元数据、版本历史。
- [ ] M2.5：Realtime 多人同步和冲突提示。
- [ ] M2.6：团队邀请、成员管理和角色权限。

## 安全约束

- 浏览器只使用 Supabase publishable key。
- service_role / secret key 只能留在可信服务端，禁止写入 Web 环境变量。
- 音频 bucket 必须保持 private。
- 所有项目与素材读写均由 RLS 限制到工作区成员。
- 素材版本新增，不静默覆盖旧对象。
- 大文件上传采用后续实现的可恢复上传方案。

## 验收要求

- 未登录用户无法读取工作区、项目、素材和音频对象。
- 不同工作区成员之间的数据隔离有效。
- 新建工作区后，创建者自动成为 admin。
- 普通 viewer 不能上传、修改或删除素材。
- 两个已授权浏览器会话能收到同一项目素材的实时变更。
